# 城市末端配送模拟

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Element Plus、Leaflet
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

楼宇自提柜已接入订单流转，数据全部保存在浏览器 localStorage 中（订单资料、格口规则、存取记录各一个 key，互不干扰），不增加任何依赖。

## 流转规则

1. **点到柜占格**：订单（未分配 → 配送中）点到柜时，按包裹大小（小/中/大）和温区（常温/冷链）匹配可用格口；小包可进大格，优先分配最贴合的格口。
2. **冷链限制**：冷链件只能进冷藏格，没有冷藏空位时该柜不可选。
3. **格口互斥**：格口未释放前不能接第二单；取件、换柜、超时回仓都会立即释放格口。
4. **六位取件码**：入柜自动生成不重复的 6 位数字码；错码、已取件码重复使用、包裹已转待办都会被拦截，拦截同样写入存取记录。
5. **超时回仓**：超过订单约定存放时长（每秒扫描）自动转为“回仓待办”，原格口立即归还、取件码作废；登记后变为“已回仓”。
6. **骑手换柜**：先释放旧格口并作废旧码，再占用目标柜新格口、换发新码；目标柜无适配格口时旧格口保持占用，取件截止时间不顺延。
7. **冻结与补录**：已取件订单冻结，不能再入柜/换柜/删除；“补录交接”必须填写原因，订单上永久保留旧值审计并写入存取记录。

## 目录结构（数据与页面分离）

```
src/
├── types.ts                    领域模型：订单/格口/记录
├── data/
│   ├── options.ts              骑手、时段、状态等选项
│   ├── lockers.ts              格口规则：柜机与格口布局（localStorage key: *-lockers-v2）
│   └── seed.ts                 订单资料与存取记录的演示种子（keys: *-orders-v2 / *-access-logs-v2）
├── services/
│   ├── storage.ts              localStorage 读写
│   ├── compartments.ts         格口匹配、占用判断、取件码生成
│   ├── format.ts               时间/倒计时格式化
│   └── store.ts                单一数据源与全部流转操作（落规则 + 写记录 + 本地保存）
└── components/
    ├── OrderPanel.vue          订单流转页面交互
    ├── LockerPanel.vue         格口占用可视化
    ├── PickupPanel.vue         客户取件开柜 + 到柜通知
    └── LogPanel.vue            存取记录查询
```
